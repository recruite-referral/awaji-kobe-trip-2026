# 淡路島と、神戸へ。

2026年11月21日・22日、ふたりの旅しおり。

表紙・2日分の日程・スポット紹介・地図・グルメマップの全15ページ。画像とリンク付きで、スマートフォンの横スワイプに対応しています。

## 公開

GitHub Pagesで `main` ブランチのルートを公開ディレクトリに設定します。ビルドは不要です。

## 編集

- `index.html`：表紙と行程
- `guides.js`：スポットの紹介文・写真・公式リンク
- `maps.js`：2日分の地図・地点
- `app.js`：ページ移動
- `style.css`：デザイン

写真の出典は各紹介ページ内に記載。地図はLeaflet 1.9.4とOpenStreetMapを利用。個人の旅行用しおりであり、サンリオや各施設の公式サイトではありません。
